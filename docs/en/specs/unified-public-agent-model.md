# Unified Public Agent Model

The public model has four concepts: `Agent` is reusable identity and capability, `Run` is one execution, `Session` is continuity, and `Workflow` is multi-agent orchestration. Ordinary applications use `createAgent`, `agent.run`, `agent.stream`, `agent.session`, `agent.remember`, `agent.recall`, `agent.delegate`, and `agent.workflow`.

The implementation specification is maintained in the Chinese source document at `docs/specs/unified-public-agent-model.md`; this page records the English public entry point and terminology.
