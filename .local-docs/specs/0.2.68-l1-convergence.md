## Objective

P8 批 4（删除批）：把 0.2.67 立窗的 deprecation 全部兑现为真删除，并完成 DeepStrike Runtime Language 的 L1 收敛：

1. **DEL-1 删除**：`CoreMessage.token_count` / `ToolResult.token_count` 字段 + 四 SDK 镜像 + 全部压制层。权威唯一化 = engine 重算（内核）/ TokenMeasurement 侧表（host 概念）/ usage·attempt 证据面（真实 provider 计数）。
2. **DEL-3 删除**：`ContentPart::Image{data}` / `Audio{data}` inline base64 + 三构造器 + 四 SDK 镜像。canonical 层不再持大对象字节，DurableSource 物化 = adapter L0 职责（P3 §1.4）。
3. **DEL-4 收敛**：删 `Message` 双别名（crate root + `types::message` 模块级——后者是 0.2.67 审计纠偏 `2d2dce8c` 新增的深路径宽限），`ContentPart` 降级为渲染期投影注记落笔。
4. **语言体系收敛**：所有新增或迁移的边界对象必须标明 `Intent/Fact/Decision`、`Canonical/Wire/Internal/Durable`、Authority 与 Causation；provider 侧统一使用 `encode/decode/normalize/render/materialize`，资源账务统一使用 `Measurement/Settlement`。

**路线图定性**：Public surface breaking（非 ABI rev）；**风险最高的一版**，必须在强门禁保护下进行。

## Boundaries

**Always**：
- S0 未过不开工；S1 红→绿演示未过不进 S2–S4
- 四 SDK 同步删除（不留单端过渡态）
- 每片提交前全矩阵绿；链验证器对 golden journal 全绿
- 分类裁决先于删除（Q-A 三分法，逐点过权威矩阵）

**裁决**：
- **Q-A**：sub-agent result wire 的 `token_count`（node `types/agent.ts` ↔ python `types/agent.py`）与 replay fixture 的 `tokenCount` 归入 wire 词表豁免；删除会改 host↔kernel 节点契约，本版保留。runtime message projection 与 adapter usage 写点仍按 DEL-1 分类处理。
- 任何读点 engine 重算替代后预算算术出现行为差的场景

**Never**：
- 动 `StoredMessageState.tokens`（冻结记账锚）、wire 词表、SessionLog 词表
- 删 `DurableSource::Base64`
- 拆三个 binding 根 allow（出身 capability ABI，另案审计）
- 动 Kernel ABI rev（本版 = public surface breaking，非 ABI rev）
