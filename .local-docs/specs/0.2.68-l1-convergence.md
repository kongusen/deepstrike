## Objective

P8 批 4（删除批）：把 0.2.67 立窗的 deprecation 全部兑现为真删除，完成 L1 收敛：

1. **DEL-1 删除**：`CoreMessage.token_count` / `ToolResult.token_count` 字段 + 四 SDK 镜像 + 全部压制层。权威唯一化 = engine 重算（内核）/ TokenMeasurement 侧表（host 概念）/ usage·attempt 证据面（真实 provider 计数）。
2. **DEL-3 删除**：`ContentPart::Image{data}` / `Audio{data}` inline base64 + 三构造器 + 四 SDK 镜像。canonical 层不再持大对象字节，DurableSource 物化 = adapter L0 职责（P3 §1.4）。
3. **DEL-4 收敛**：删 `Message` 双别名（crate root + `types::message` 模块级——后者是 0.2.67 审计纠偏 `2d2dce8c` 新增的深路径宽限），`ContentPart` 降级为渲染期投影注记落笔。

**路线图定性**：Public surface breaking（非 ABI rev）；**风险最高的一版**，必须在强门禁保护下进行。
